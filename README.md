# Placitum

마인크래프트 자바 에디션 모드. **종으로 지정한 마을이 스스로 인프라를 짓는다.**

> *placitum* — 카롤링거 시대의 공개 집회. 영주와 자유민이 모여 안건을 다루던 자리.

## 해결하려는 문제

**밤에 몬스터가 주민을 죽인다.** 이게 처음부터 유일한 문제였다. 답은 **빛**이다 — 스폰을 정하는 것은 밝기다. 이 모드는 그 답을 마을이 스스로 깔게 한다. 왜 이전 설계(습격 시뮬레이션)를 갈아엎었는지는 [docs/why-the-reset.md](docs/why-the-reset.md).

## 어떻게

종에 **시프트 + 우클릭**. 그게 이 모드가 월드에 추가하는 유일한 상호작용이고, 등록되지 않은 마을은 코드를 한 줄도 타지 않는다.

등록된 마을은 세 단계를 올라간다. 각 단계는 **동사**다:

| 단계 | 열쇠 | 마을이 하는 일 |
|---|---|---|
| **빛** | 종 | 가로등. 모드의 약속은 여기서 이미 다 지켜진다 |
| **성장** | 촌장의 탁자를 누가 잡음 | 도로, 집, 밭 |
| **방어** | 영주의 탁자를 누가 잡음 | 성벽·성문·초소 |

열쇠는 전부 **플레이어가 놓는 작업대**고, 그걸 잡는 것은 **바닐라 주민**이다. 직업은 작업대가 정하고, 번식은 침대와 음식이 정하고, 죽음은 몹이 정한다 — 그중 무엇도 대신 계산하지 않는다. 우리가 하는 일은 블록을 놓는 것뿐이다.

- 촌장은 **영주의 인장**을, 영주는 **골렘의 심장**을 판다. 영주의 탁자와 **수호상**(철골렘 하나를 세우고, 죽으면 다시 세운다)은 그 재료 없이 못 만든다. 종은 잠그지 않는다 — 작은 마을로 남기고 싶을 수도 있으니까
- 촌장은 **자유민의 증서**도 판다 — 땅에 쓰면 주민 하나. 두 번째 마을을 열 때 데려가는 한 가족이다. 비싸고 몇 장 안 판다
- 재료는 **바이옴**이 정한다. 사막 마을은 사암으로, 타이가는 가문비나무로
- 도시계획은 **종 위치의 산술**이다. 주기 20 = 도로 3 + (여유 1 + 부지 7) × 2 + 여유 1. 탐색하지 않는다
- **걸어갈 수 없는 곳에는 아무것도 짓지 않는다.** 물·얼음·절벽에서 길이 끊기고, 가파른 부지는 짓지 않고 기다린다 — **플레이어가 평지를 만들어주는 것이 의도된 고리다**
- 성문·초소는 **플레이어가 크리에이티브에서 지은 것**을 구조물 블록으로 저장해 넣은 템플릿이다. 모양을 바꾸고 싶으면 코드가 아니라 월드에서 바꾼다
- 아무것도 안 할 때는 **왜 안 하는지 말한다.** `/placitum build`, 종 시프트+우클릭, 30초마다의 로그가 같은 것을 보여준다

| 항목 | 값 |
|---|---|
| Minecraft | 26.2 (Java Edition) |
| 모드로더 | NeoForge 26.2.0.88 |
| Java | 25 |
| modid | `placitum` |
| 배포 | CurseForge — [PUBLISHING.md](PUBLISHING.md) |

```bash
./gradlew build        # 빌드 + 테스트
./gradlew runClient    # 클라이언트 실행
./gradlew test         # 순수 함수 테스트 (월드 없이 돈다)
```
