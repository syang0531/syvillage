# SY Village

마인크래프트 자바 에디션 모드. **마을에 대해 플레이어가 할 수 없는 것만 준다.**

마을을 키우는 것은 당신이다. 이 모드는 연장을 준다. **자동으로 해주는 것은 없다.**

## 해결하려는 문제

**마을을 키우는 일이 너무 오래 걸린다.** 그리고 그중 대부분이 재미없는 부분이다 — 평탄화, 자재 나르기, 같은 집을 손으로 스무 번 짓기.

몹은 여전히 밤에 주민을 죽인다. 그 답은 **떠나지 않는 골렘**과 **침대 있는 집**이고, 둘 다 이 모드가 준다. 빛은 당신이 놓는다 — 어디가 어두운지는 밤에 서 있으면 보인다.

0.2까지는 모드가 빛을 직접 깔았다. 격자로, 필요량의 다섯 배 밀도로, 고를 수 없는 자리에. 왜 갈아엎었는지는 [docs/concept-0.3.md](docs/concept-0.3.md).

## 무엇이 들어오는가 — 세 관문

전부 통과해야 기능이 들어온다.

1. **손으로 못 하는가?** (삽이면 되는 길 → 탈락)
2. **마을에 관한 것인가?** (범용 건축 도구 → 탈락)
3. **플레이어가 결정하는가?** (자동 → 탈락)

통과한 것은 셋이다.

| 요소 | 왜 손으로 못 하나 |
|---|---|
| **도면** | 바닐라 마을 건물 171채를 지형에 맞춰, 바이옴 재료로 |
| **수호상** | 골렘을 영구히 붙들어 둔다. 바닐라 골렘은 주민의 기억에 묶여 있다 |
| **개척 키트** | 마을 지도 · **종**(조합할 수 없다) · 자유민의 증서 |

> **한 번 들어왔다 나간 것:** "어디가 어두운지 보여주기". 블록광은 눈에 안 보인다는 게 근거였는데, 플레이해 보니 **밤에는 어두운 데가 보인다** — 관문 1을 통과 못 한다.

## 어떻게

### 건물

**건축가의 탁자**에 도면을 꽂으면 그 옆에 건물이 그려진다.

| | |
|---|---|
| 좌표 X / Y / Z | 탁자 기준 상대 좌표. 시프트 + ± 는 건물 크기만큼 |
| 방향 | 90°씩 |
| 윤곽 | 켜기 / 끄기 |
| 짓기 | 도면 한 장 소모, 탁자는 남는다 |

**윤곽은 셋이다** — 하얀 육면체(상자 크기) · 초록/빨강 테두리(블록이 서는 칸) · 반투명 실루엣(무엇이 지어지나). 자리를 차지한 블록은 빨간 큐브, 바닥 밑이 빈 칸은 노란 큐브.

**타이머가 없다.** 탁자가 서 있는 동안 윤곽도 서 있으니, 막는 블록을 캐러 갔다 와도 그대로다. 동시에 둘을 배치하려면 탁자를 둘 짓는다.

### 놓는 규칙은 침대와 같다

**차지할 자리가 전부 비어 있어야 한다.** 아니면 안 놓인다.

- **채우지 않는다.** 기단도 기초도 없다 — 밑을 비워두는 게 의도일 수 있다
- **깎지 않는다.** 언덕이 들어오면 거절
- **베지 않는다.** 나무가 서 있으면 거절
- **덮어쓰지 않는다.** 남의 집에 겹치면 거절

넷 다 **미리보기가 어느 칸인지 보여주므로 잡일 지시가 아니라 정보다.** 지지대는 안 묻는다 — 침대 머리맡이 절벽 밖으로 나가도 놓이듯, 절반이 허공인 집도 놓인다.

### 사람과 건물

| 직업 | 작업대 | 판다 |
|---|---|---|
| **촌장** | 촌장의 탁자 | 마을 지도 · **종** · **자유민의 증서** |
| **건축가** | 건축가의 탁자 | **도면** — 등급이 오를수록 큰 건물, 그다음 성벽·성문·초소, 마지막에 수호상 |

**건축가는 자기 바이옴의 건물만 그린다.** 사막 마을에서는 사막 집이 나오고, 타이가 집이 필요하면 타이가로 가야 한다. 그리고 한 등급의 거래 중 둘만 나오므로 **건축가마다 그리는 게 다르다.**

**종을 파는 것이 바닐라의 진짜 빈틈이다** — 조합할 수 없어서 남의 마을에서 뜯어오는 것 말고는 구할 방법이 없다.

## 바닐라를 건드리지 않는다

직업은 작업대가 정한다. 번식은 침대와 음식이 정한다. 죽음은 몹이 정한다. **그중 무엇도 대신 계산하지 않는다.**

진행도 바닐라가 잡는다 — 도면은 건축가의 거래 등급으로 풀리고, 등급 오른 주민은 내려가지 않는다.

**이 모드는 영속 상태를 갖지 않는다.** `SavedData`도, 마을 등록도, 클레임도 없다. 탁자가 기억하는 것은 블록 엔티티 NBT고, 부수면 사라진다.
