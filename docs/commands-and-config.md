# 상호작용과 설정

> 2026-09-21에 다시 썼다. 이전 판은 마을 등록, 격자, `/syvillage` 명령어를 설명하고 있었고 **그 셋 다 없다.** 설계는 [`concept-0.3.md`](concept-0.3.md).

## 명령어는 없다

`/syvillage`는 사라졌다. 등록할 마을도, 집계할 부지도, 취소할 큐도 없어서 명령할 것이 남지 않았다.

## 월드에서 하는 것

종은 그냥 종이다. 이 모드가 종에 거는 것은 아무것도 없다.

### 건물 — 건축가의 탁자

| 동작 | 결과 |
|---|---|
| 우클릭 | 제도판이 열린다 |
| 슬롯에 도면 | 꽂으면 윤곽이 뜬다. 스택으로 넣을 수 있다 |
| X / Y / Z | 탁자 기준 상대 좌표. 치는 대로 건물이 걸어간다 |
| **시프트 + ±** | **건물 크기만큼** 한 번에 — 성벽 조각을 이어 놓을 때 |
| 방향 | 90°씩 |
| 윤곽 | 켜기 / 끄기 |
| 짓기 | 도면 한 장 소모. 화면은 안 닫히고 탁자는 남는다 |

탁자를 부수면 도면이 떨어지고 윤곽이 사라진다.

### 주민 — 두 작업대

주민이 탁자를 잡아야 직업이 생긴다. 놀고 있는 성인 주민이 있어야 하고, 그건 바닐라가 정한다.

| 작업대 | 직업 | 조합 |
|---|---|---|
| 촌장의 탁자 | 촌장 | 판자 × 6, 종, 종이 × 2 |
| 건축가의 탁자 | 건축가 | 돌벽돌 × 6, 금괴 × 2, 종이 |

**수호상은 조합할 수 없다.** 건축가가 5등급에 판다.

## 설정

`run/config/syvillage-common.toml` — 서버가 정한다.

### `[blueprint]`

| 키 | 기본 | 무엇 |
|---|---|---|
| `raiseBlocksPerTick` | 40 | 건물이 올라가는 속도. **연출일 뿐** — 블록은 이미 정해져 있고, 서버가 꺼지면 남은 것이 즉시 완성된다. 20000이면 즉시 |
| `maxDrawingOffset` | 64 | 탁자에서 도면을 얼마나 멀리 밀 수 있나 |
| `drawingRefreshTicks` | 20 | 탁자가 지면을 다시 읽는 주기. 막는 블록을 캐고 오면 빨강이 초록이 되는 것이 이것 |
| `drawingWatchRange` | 48 | 그 재측량을 할 만큼 플레이어가 가까운 거리 |

### `[guardian]`

| 키 | 기본 | 무엇 |
|---|---|---|
| `guardCheckTicks` | 200 | 수호상이 제 골렘을 찾는 주기 |

### 클라이언트 — `syvillage-client.toml`

표시 취향이라 서버가 정하지 않는다. 제도판의 슬라이더 둘이 이 값을 쓴다.

| 키 | 기본 | 무엇 |
|---|---|---|
| `massOpacity` | 26 | 건물 실루엣의 진하기 (0~255). 0이면 윤곽선만 |
| `markOpacity` | 153 | 자리를 차지한 블록과 바닥 밑 빈 칸 표시의 진하기 |

## 데이터팩으로 바꿀 수 있는 것

| 파일 | 무엇 |
|---|---|
| `data/syvillage/blueprint_catalogue.json` | 건축가가 그릴 수 있는 건물 목록과 치수 |
| `data/syvillage/villager_trade/**` | 거래 하나하나 |
| `data/syvillage/tags/villager_trade/architect/level_N.json` | 어느 등급에 무엇이 나오나 |
| `data/syvillage/structure/*.nbt` | 성벽·성문·초소의 **모양**. 크리에이티브에서 지어 구조물 블록으로 저장하면 된다 |

카탈로그는 게임의 구조물에서 생성한다. 게임이 바뀌면 테스트가 먼저 깨진다:

```bash
./gradlew test -Psyvillage.writeCatalogue
```
